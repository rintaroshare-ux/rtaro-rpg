## 制作

既存ゲームの曲・MIDI・録音を使用せず、15種類の独自モチーフと和声進行を作成しました。主旋律、対旋律、弦の三和音、ベース、ハープ分散和音、サンプルドラムを重ね、A/A'/B/Cの展開を持つ24〜32小節のスコアにしています。勝利・敗北は8小節です。通常曲は約1分〜80秒。フルスコアは `scripts/render-soundtrack.py`、モチーフと編成情報は `public/audio/compositions.json` にあります。

FluidSynthとTimGM6mbの楽器サンプルを使ってオフラインで演奏・書き出しし、22050Hz・12bit相当の振幅量子化によってサンプル音源を使う16bit時代の質感を目指しています。単一の矩形波をブラウザで鳴らす従来方式とは異なります。ループ曲は2周レンダリングして2周目を切り出し、前周の残響を先頭に含めています。

再制作には libfluidsynth、TimGM6mb.sf2、Python/numpy、ffmpegが必要です。ゲーム起動・npm buildには不要です。

```sh
python3 scripts/render-soundtrack.py       # 全曲
python3 scripts/render-soundtrack.py oslo  # 指定曲
```

TimGM6mbの著作者・出典・GPL-2.0と音楽の配布条件は `public/audio/CREDITS.md` と `LICENSE.txt` に記載しています。SoundFont本体は同梱していません。既存ゲームの素材は使用していません。

## 再生

ユーザーのキー／タップ操作後にAudioContextを開始します。音声ファイルの取得・デコードとシーンの進行は独立しており、取得失敗でもゲームは続き、通知と再試行ボタンを表示します。曲の切り替えは0.65秒のクロスフェード。勝利ファンファーレを経て現在の章の曲へ戻り、ショップを閉じた場合も章の曲を復元します。

デコード済みキャッシュは3曲までに制限します。一時停止・アプリ切替で停止し、再開時は保存した再生位置から続けます。BGM音量と効果音音量は独立したGainNodeで管理し、設定を保存します。上部の音量はBGM、一時停止画面にはBGMと効果音のスライダーがあります。効果音は短い独自PCMの打撃・回復音を別バスで再生します。

## 検証と限界

単体テストは15ファイルのOggヘッダー、ハッシュの相違、15モチーフの相違、章と戦闘の選曲を確認します。`tests/browser/music.mjs` は実際のデコードと非無音波形、操作前ロック、全章曲、ショップ復帰、強敵・ボス・パパ戦、勝利からの復帰、感動・エンディング、音量の分離、一時停止、取得失敗からの再試行を確認します。

動作確認はChromiumです。Android実機、端末スピーカー／イヤホンでの聴感、曲全体の人による試聴・ループ境界の聴感評価は未実施です。SFCの市販作品と同水準の品質を保証するものではなく、音色・編曲・音量バランスには今後の試聴調整の余地があります。不足する曲IDはありませんが、上記の音楽的評価を完了扱いにしていません。
