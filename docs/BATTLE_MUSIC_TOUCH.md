# 右側の仲間とオリジナルBGM

## 戦闘画面

敵を左側、加入済みの仲間を右側の縦の隊列に配置しました。4人それぞれの32×48 PNGを左向きで表示し、行動中の前進・復帰、被弾の点滅、戦闘不能時の横倒れを表現します。回復やダメージの演出は実際の仲間の位置に表示します。

下側は左がコマンド、右がHP/MP・ATB、最下段がログです。コマンドのボタン、敵、回復対象の仲間、ATBモード表示をクリック／タッチできます。満タンの仲間スプライトをタップすると行動する仲間を切り替えます。キーボード操作は維持しています。

構図や操作感の参考は古典的な横並び型RPGですが、既存作品の画像・コード・音楽・メロディは使用していません。戦闘計算・敵AI・セーブ形式には変更を加えていません。

## 音楽

Web Audioでこのゲーム用に作成したオリジナルのチップチューンを再生します。外部音源・音楽ファイルのダウンロードは不要です。

- タイトル：海を越える小さな約束
- 探索：こすぎの散歩道
- 通常戦：ぬいぐるみ大行進
- ボス：モフモフの王冠
- 勝利：ひとさじの勇気
- 敗北：また、家から

メロディ、ベース、伴奏、パーカッションの譜面は`src/audio/scores.ts`、再生処理は`src/audio/music.ts`です。ゲーム起動直後はブラウザの自動再生制限に従い、最初のキー入力またはタッチ後に再生します。右上の音楽ボタンでも開始できます。

音量スライダーとON/OFFを用意しました。設定は`rtaro.audio.v1`に保存し、RPGのセーブデータを変更しません。場面が変わると前の音を止めて切り替え、複数の曲が重ならないよう単一のAudioContextとトランスポートを共有します。タブ非表示では停止し、戻ると再開します。勝利・敗北曲は一度だけ再生します。AudioContextが使えなくてもゲームは続行できます。

## スマホの基本操作

タッチ端末では仮想十字キー、決定、戻るを表示します。戦闘中には仲間切替・ATB切替も表示します。十字キーは押し続けて移動し、離す・キャンセル・タブ移動・シーン切替で解除します。キーボード入力と同じ会話・メニュー処理を利用し、保存処理も共通です。

横画面を推奨し、画面の左右に操作ボタン、中央に16:9のゲーム画面を配置します。縦画面では横向きの案内を表示します。タッチ端末ではページスクロールとブラウザのスクロール動作を抑止します。

ショップ・装備はまだ未実装です。Android実機そのものでの確認は未実施ですが、Chromiumのモバイル・タッチ相当環境（915×412）で移動、会話、保存、コマンド・対象選択を確認しています。
