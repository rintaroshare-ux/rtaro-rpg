# Phase 3：スマートフォン対応（Ver.2.3）

Android Chromeを対象に、論理解像度640×360・16:9・pixelArtを維持した可変レイアウトを実装しました。横向き推奨ですが、縦向きでも画面と操作ボタンを分離して表示します。

## 操作

- 仮想十字キー：移動。押したまま別方向へスライドできます。複数指での入力、指を離す・キャンセルする・画面を切り替える際の解除に対応します。
- 決定／戻る：会話、メニュー。戦闘では仲間切替とATBモード切替も利用できます。
- 会話、戦闘コマンド、道具・装備、購入・売却は大きなHTMLボタンで直接選択できます。長いメニューはパネル内でスクロールします。
- 上部の一時停止ボタン：ゲームを停止し、音量、大きなメニューの有無、タッチ／キーボード操作を設定できます。PCはSpaceでも停止できます。
- 全画面ボタン：ブラウザが許可する場合に全画面へ切り替えます。横向き固定が許可されない端末では手動で回転してください。拒否された場合も通常表示で続けられます。
- 画面回転・別タブへの移動・ウィンドウのフォーカス喪失で自動停止します。復帰後は「ゲームを再開」を押します。アクティブATBも停止中は進みません。

## セーブ

通常の保存ボタン・メニュー保存・既存の自動保存は従来の保存先を維持します。画面回転やバックグラウンド移行時は別の中断保存先 `rintaro.chapter1.autosave.v3` に保存し、通常の保存を上書きしません。タイトルの「中断から（自動保存）」で読み込めます。戦闘中は敵HP・ATB・予約行動も再開します。

保存形式はv3のままです。v1／v2からの移行と既存の通常セーブを維持します。LocalStorageへの書き込みに失敗すると画面内で通知します。OSが即座にブラウザを終了した場合は最後の中断保存以後の操作を復元できないことがあります。端末間共有はありません。

## 実装

`input/mobileLayout.ts` はPhaser非依存のレイアウト計算、`touchState.ts` は指ごとの方向管理、`mobileViewport.ts` は安全領域・visualViewport・全画面、`pause.ts` は停止と中断保存、`mobileMenu.ts` は各Sceneから受け取るメニューモデルの表示を担当します。ゲームの取引・装備・戦闘処理は従来の関数を呼び出します。

Phaserの親領域を再測定してからスケールを更新し、回転直後の旧サイズが残る問題を防ぎます。640×360の内部座標やテクスチャキーは変更していません。

## 検証

```sh
npm test
npm run build
# 別ターミナルで npm run dev
npm run test:mobile
npm run test:browser
npm run test:pages
```

単体テスト42件。Chromiumのタッチエミュレーションで390×844、568×320、667×375、740×360、915×412、820×1180の回転・リサイズ、移動とスライド・複数指・キャンセル、大きな戦闘メニュー、一時停止、通常保存を保護した中断再開、全画面拒否時の復帰、売買・装備を検証します。既存の第1章クリア・戦闘・保存拒否時の継続はブラウザ回帰テストで確認します。本番ビルドは `/rtaro-rpg/` 配下で別途検証します。

Android実機によるブラウザUI・全画面・OSバックグラウンド復帰の確認は未実施です。Phase 4の敵15種類以上・ボス等の新規PNG素材はこのフェーズには含みません。
