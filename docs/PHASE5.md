# Phase 5：海鮮丼をノルウェーへ

第1章クリア画面の決定ボタンから羽田空港へ続けられます。旧クリアセーブを読み込んでも同じ入口を使用できます。

追加した8マップは、羽田空港／手荷物ベルト、飛行機の客室／雲の航路、オスロの街／フィヨルド、会社／終わらない会議室です。各章に会話と選択式の課題6件、ショップ、無料回復所、宝箱2個、中ボスと章ボスを配置しています。課題は案内、荷物の仕分け、機内の救援、風向き、現地の言葉、渡船、仕事の分担と家族の約束を題材にしています。間違えた選択は何度でもやり直せます。

町の課題3件でダンジョンへ、ダンジョンの課題3件と中ボスの勝利で章ボスへ、章ボスの勝利で次章へ進めます。課題には順序の条件もあります。正解報酬は一度だけで、経験値・お金・全回復を獲得します。必要な品を売ることで進行不能になる条件はありません。敗北時は現在の章の町で全回復し、物資を補充します。解決済み課題を失いません。

章別の通常敵は各3段階で、加入メンバーの平均レベルに応じて編成を選びます。雑魚は最大3体です。各章の中ボス・章ボスは固有名・能力を持ち、3形態のAIを使用します。章別敵の絵は既存のオリジナルPNGを再利用し、パパには新しく生成した専用PNGを使用します。新装備は雲渡りの杖、オーロラコート、おかえりの指輪です。

仕事に取り憑かれたパパを倒し、出口で海鮮丼を渡すとエンディングになります。配達済みセーブをロードするとエンディングから再開します。各章の左の出口で戻れます。

保存構造は既存v3を維持し、マップIDと文字列フラグの定義を拡張しました。旧v1/v2/v3を読み込み、新しい章の座標・課題・宝箱・勝利フラグ・戦闘中HP/ATBも保存します。会話や選択画面の途中で保存した場合は、その場から会話を再開して選び直せます。保存失敗時は通知し、継続できます。

単体テストは全章のゲート、報酬の一度限り取得、新マップ保存、配達の条件、敗北復帰、8ボスの実ATBシミュレーションを確認します。ブラウザテスト `node tests/browser/campaign.mjs` はタッチで全課題・マップ・章遷移・配達とエンディングロードを確認します。ブラウザ内のボス戦だけは結果遷移用の短縮フィクスチャを使い、戦闘バランス検証を代替しません。

全章約1時間は設計目標であり、実プレイヤーの通しプレイ時間は未計測です。Android実機と人による難易度・文章の評価は未実施です。
