# Ver.2.2：最大3体・成長調整・いつでも保存・Phase 2

## 既存ゲームの調整

- 雑魚敵は最大3体。1人の間は1体のみ、仲間の人数に応じて上限を増やします。戦闘コントローラーも4体編成を拒否します。
- 経験値をくま18→30、うさぎ22→36、ボス180→280へ増やしました。レベルアップ条件は変更せず、既存レベル・蓄積経験値を維持します。
- 画面左上の「保存」とPキーで、会話・戦闘・ショップ・装備画面からも保存できます。タイトル／ロード前は無効にし、既存の保存を新規状態で上書きしません。

## 保存と再開

戦闘では敵のHP・フェーズ・行動回数、味方のHP/MP、ATB、防御状態、逃走試行回数、予約行動、報酬付与済み情報を保存します。演出中も保存できます。再開はその行動の計算が終わった地点からで、演出そのものを繰り返しません。勝利直後の保存でも報酬を二重取得しません。

会話・店・装備の途中保存は、再開時にフィールドへ戻ります。購入・使用・装備済みの変更は維持します。会話は完了時に進行イベントを確定するため、会話中保存からは必要に応じてそのNPCと話し直します。

形式をv3にし、`rintaro.chapter1.v3`に保存します。v3がなければv2→v1の順に読み込みます。旧キーは削除しません。v1/v2の所持金・道具・レベル・位置・進行を維持し、装備なし、特上海鮮丼0個、戦闘中断なしで移行します。既存のv3が不正な場合は、勝手に旧版へ巻き戻しません。

保存失敗は画面上部の通知に表示します。保存失敗で会話や戦闘を停止しません。保存先は同じブラウザ・同じサイトのLocalStorageです。別端末との同期機能はありません。

## Phase 2：ショップ

商店街の魚屋さんと旅道具屋に話しかけるとショップが開きます。魚屋さんは初回に海鮮丼3個を分けてくれます。ママは旅のしたく金100Gを一度だけ渡します。旧セーブでも、未受領ならママと話して受け取れます。

- 道具店：海鮮丼、特上海鮮丼、潮風ソーダ、目覚めの塩。
- 装備店：4人それぞれの武器、防具2種、アクセサリー3種。
- 売却価格は購入価格の半分。装備中の品は外すまで売れません。
- 伝説の海鮮丼は重要アイテムとして、売買・消費候補から除外しています。
- キーボード：上下で選択、左右で購入／売却、Q/Eで1個／5個、決定で取引、戻るで閉じる。
- タッチ：品物を選び、購入／売却ボタンで確定。個数・ページ・売買モードもタップで変更できます。

所持金不足・不正な個数・未所持の品の売却は取引前に拒否し、所持金や道具を変更しません。ショップ中はフィールドを停止し、ランダムエンカウントが起きないようにしています。

## 道具・装備

フィールドメニュー（X／戻る）の「どうぐ・装備」から開きます。Tで道具／装備、Q/Eで仲間、左右で装備枠、上下で候補、決定で使用・装備。各タブや仲間・品物はタップでも選べます。

特上海鮮丼は対象のHP180回復、潮風ソーダはMP25回復、目覚めの塩は戦闘不能からHP半分で復帰します。道具はフィールドと戦闘の双方で使用できます。

装備は武器・防具・アクセサリーの3枠。キャラクター専用武器や装備制限があります。購入しただけでは装備されません。装備時に所持品から移動し、外した品は所持品へ戻します。装備効果は攻撃・魔法・防御・すばやさ・最大HP/MPへ反映します。最大HP/MPが減った際は現在値も上限に収め、付け替えで無限回復しないよう現在値は増やしません。

道具・装備画面は変更候補の能力比較を表示します。装備中の品や未所持の品を重複して売却・装備することはできません。

## 実装と検証

- `game/economy/catalog.ts`：品物・価格・装備制限・効果。
- `game/economy/model.ts`：売買・付け替え・使用の計算。Phaser非依存。
- `game/economy/stats.ts`：装備を含めた能力計算。
- `game/combat/snapshot.ts`：戦闘保存の形式・検証。
- `scenes/Shop.ts`、`scenes/Inventory.ts`：独立した画面と入力。
- `input/saveControls.ts`：全プレイ画面の保存操作と通知。
