# Phase 4：グラフィック強化（Ver.2.4）

第1章の戦闘・探索に新規PNGを組み込みました。画像生成で作成したオリジナル素材を使用し、既存ゲームの画像・音楽・コードは利用していません。

## 敵とボス

通常敵は16種類です。くま、うさぎ、キツネ、ネコ、ワンコ、パンダ、ペンギン、フクロウ、アザラシ、カメ、カエル、ヒツジ、アライグマ、ハリネズミ、ラッコ、レッサーパンダが、それぞれ異なる名前・姿・HP・すばやさ・弱点・報酬を持ちます。`src/game/bestiary.ts` で定義します。

1人のときは4種類、2人では8種類、3人以上で全16種類が遭遇候補になります。通常敵の同時出現は最大3体です。歩数・安全地帯の判定は維持し、敵シンボルは配置していません。元のくま・うさぎ・ボスの能力と報酬は維持しています。

通常敵は64×64の独立PNGを48×48で表示します。モフモフキングは96×96の専用PNGを96×96で表示し、王冠・マント・星の杖を備えます。3形態のAIを維持し、形態に合わせて色を変化させます。敵はTweenで小さく上下動します。仲間の4方向歩行スプライトシートは従来の32×48・各方向3フレームを維持します。

## NPCと宝箱

ママ、公園のおじさん、魚屋さん、旅道具屋に32×48のPNGを使用します。既存の会話・加入・ショップ入力は変更していません。

公園に海鮮丼2個、駅前に50Gと潮風ソーダ2本の宝箱を配置しました。近づいて決定すると取得し、開いた画像に変わります。取得フラグと報酬をまとめて変更し、再度調べても増えません。取得結果を保存し、ロード後も開いた状態を維持します。保存失敗時は通知し、ゲームを続けられます。

## 魔法と素材管理

雷・水・回復・闇・蘇生に発動リングを追加しました。既存の稲妻・水流・回復パーティクル・闇の渦・画面揺れを維持し、戦闘の乱数やATB計算から演出を分離しています。

`src/graphics/spec.ts` の `sceneAssets` がPNGパスと寸法を定義します。`scripts/prepare-phase4-atlas.mjs` は生成マスターから各素材を切り出し、余白と足元を揃えます。実行方法は同スクリプト冒頭に記載しています。元のマスターはゲーム実行・ビルドには不要です。PNG欠落・寸法不正時は各キーの仮画像へフォールバックします。

旧キー・仲間ID・マップ・進行フラグは維持しています。保存形式はv3のままで、旧v1/v2/v3の読み込み・中断保存に対応します。新しい敵を含む戦闘のHP・ATB・予約行動も保存できます。宝箱は既存の文字列フラグを使用するため、保存の構造変更はありません。

## 検証

```sh
npm test
npm run build
# 別ターミナルで npm run dev
npm run test:phase4
npm run test:browser
npm run test:pages
```

単体テストは45件。16種類の遭遇・最大3体・新敵の戦闘保存検証・宝箱の一度限り取得と保存移行・PNG寸法を確認します。Phase 4ブラウザテストでは23枚の新規PNG、全16敵の戦闘表示、ボス、宝箱の再取得防止と再読み込み、新敵の戦闘中セーブを確認します。既存のブラウザ回帰テストは加入順・ボス3形態・魔法・第1章クリア・売買と装備・タッチ操作・中断再開を対象とします。本番ビルドの `/rtaro-rpg/` 配下では計28枚のPNGを確認します。

Android実機確認、15〜20分のプレイ時間の実測調整、第2章、戦闘効果音は未実施です。

確認結果：単体テスト45件、strict TypeScriptを含む本番ビルド、Phase 4専用ブラウザテスト、第1章クリアを含む既存の全ブラウザ回帰テスト、本番パス配下の28 PNGの読み込みが成功しました。Chromiumによる確認であり、Android実機は未確認です。
